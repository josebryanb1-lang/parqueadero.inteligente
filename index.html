NUESTRA PROPUESTA

¿Qué es SMART PARKING?

SMART PARKING es un proyecto de robótica que consiste en desarrollar un sistema capaz de detectar la presencia de vehículos utilizando un sensor ultrasónico conectado a una placa Arduino. Mediante luces LED, el sistema proporciona señales visuales que permiten identificar el estado del espacio de estacionamiento.

PROCESO DE CONSTRUCCIÓN

¿Cómo se elaboró?

El parqueadero inteligente se desarrolló mediante diferentes etapas de diseño, conexión y programación.

01

Planificación

Se identificó la necesidad de crear un sistema que pudiera detectar vehículos y comunicar visualmente el estado del estacionamiento.

02

Selección de componentes

Se seleccionaron los materiales electrónicos: Arduino R1, protoboard, luces LED y sensor ultrasónico.

03

Montaje del circuito

Se realizaron las conexiones entre los componentes utilizando la placa protoboard y los pines de Arduino.

04

Programación

Se elaboró un programa para que Arduino recibiera las mediciones del sensor y controlara las señales luminosas.

05

Pruebas y funcionamiento

Se realizaron pruebas para comprobar la detección de objetos y la respuesta de los indicadores LED.

MATERIALES UTILIZADOS

Componentes electrónicos

Arduino R1

Es la unidad de control que procesa las instrucciones y coordina el sistema.

⚡

Placa Protoboard

Permite realizar conexiones electrónicas sin necesidad de soldar los componentes.

💡

PROPÓSITO ACADÉMICO

Objetivos del proyecto

🎯 Objetivo general

Diseñar y construir un sistema de parqueadero inteligente utilizando Arduino R1, una placa protoboard, luces LED y un sensor ultrasónico, con el propósito de detectar la presencia de vehículos y facilitar el control automatizado del estacionamiento.

📌 Objetivo específico

Implementar un circuito electrónico programado que utilice un sensor ultrasónico para detectar vehículos y activar señales luminosas mediante LED, permitiendo indicar visualmente el estado del parqueadero y demostrar la aplicación de la robótica y la automatización en situaciones de la vida cotidiana.
